Entry for the [make.fun bounty "The Long Roast: Lawmakers and the File They Cannot Convert"](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7): a single satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF, judged pairwise by an AI judge.

## The line

> The committee spent a year drafting AI regulation, then tabled the bill because nobody could convert it to PDF.

111 characters, one sentence. The roast lands on the gap between a year of lawmaking and a five-second file conversion nobody in the room could do.

## How it works

`main.ts` writes exactly that line (and nothing else) to `/output/entry.txt`, with a runtime guard (1–320 characters, exactly one sentence, no leading/trailing whitespace) and a byte-exact read-back verification.

```sh
node main.ts
```
